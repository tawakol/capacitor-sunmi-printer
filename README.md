# capacitor-sunmi-printer

Capacitor plugin for implementing the Sunmi printer SDK.

## Requirements

- Capacitor 8 (this version requires `@capacitor/core` 8.x).
- Node.js 22 or newer for development.
- Android: Java 21, Android SDK 36, and Android 7.0 (API 24) or newer.
- iOS builds: Xcode 26 or newer and iOS 15 or newer.

Printing requires a supported Sunmi Android device. The iOS implementation is
currently a scaffold and does not implement the printer API.

## Install

```bash
npm install capacitor-sunmi-printer
npx cap sync
```
